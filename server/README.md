### Сборка
COMPOSE_BAKE=false COMPOSE_PARALLEL_LIMIT=1 docker compose build && docker compose up -d --no-build --scale ozon-worker=1

### Планировщик и воркеры

Из каталога server выполните `python create_db.py`, чтобы добавить таблицу
parse_jobs в существующую БД. Запустите `python -m app.queue scheduler`.
Когда модуль парсера будет готов, запустите один или несколько процессов
`python -m app.queue worker my_parser:check_price`, подставив имя своего
модуля и функции. Каждый процесс использует те же настройки БД, что и API.

Функция check_price(url, marketplace_id) возвращает цену в рублях (например,
Decimal) или выбрасывает исключение при сбое. Ограничьте длительность вызова
тайм-аутом меньше пяти минут. После ошибки задание снова доступно через
минуту, после аварийной остановки процесса — по истечении пятиминутной аренды.
Обработка допускает повторный запрос к маркетплейсу. Запись результата и
удаление задания проходят в одной транзакции с проверкой токена аренды.

### Воркер Ozon

В окружении сервера установите зависимости браузера и запустите воркер
(планировщик должен работать отдельным процессом):

```bash
pip install -r requirements.txt -r requirements-ozon.txt
python -m playwright install-deps firefox
python -m camoufox fetch
python -m app.queue ozon-worker
```

Для параллельных проверок запустите несколько экземпляров последней команды.
Воркер выбирает задания маркетплейса Ozon и сохраняет первую видимую цену
в рублях из блока webPrice. Цена соответствует карточке в гостевой сессии.
Недоступная карточка или отсутствующая цена возвращаются на повторную проверку.
